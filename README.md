# Pakkā

Notes on AI, risk, governance and human judgment. Drop Markdown files in `content/`.

## Write

Add a `.md` file in `content/`:

```md
---
title: Your title
date: "2026-08-13"
---

Your post. Markdown works.
```

The filename becomes the URL (`content/my-post.md` → `/posts/my-post`).

## Run

```bash
npm install
npm run dev
```
