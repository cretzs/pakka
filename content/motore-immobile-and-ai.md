Aristotle’s *motore immobile* — the unmoved mover — is the cause that produces motion without being moved itself. Everything else in the chain is a middle term: it acts because it was acted upon. The first term does not. It is actuality, not a reaction.

That is a useful test for AI, because the product is sold as if it were a first term. A model answers. An agent books the flight. A lab says the system “decided.” The language treats the machine as the start of the motion. It is almost never the start.

## The chain does not start at inference

A model is moved by weights, and the weights are moved by data, and the data is moved by people who wrote, scraped, labeled, and permitted. At inference it is moved again: by a prompt, a tool result, a policy, a temperature setting. The output can look like origination. It is closer to a very fast last step. If you cannot name what moved it, you have not found a *motore immobile*. You have lost the chain.

## Accountability hides in the last thing we see

The interesting case is not whether the model “really thinks.” It is who we treat as unmoved when something goes wrong. If the system is the first cause, nobody is accountable. If the operator, the deployer, or the person who set the objective is the first cause, then the model is an instrument — impressive, unstable, and still an instrument. Regulation already knows this pattern. A firm does not stop being the mover because it hired a clever intermediary.[^1]

## Agents are not unmoved movers

There is a second, quieter temptation: to build an AI that needs no prompt, that starts work by itself, that looks finally unmoved. That does not escape the chain. It only hides the first move in a cron job, a standing goal, or a constitution written last quarter. The mover is still whoever set the end. Aristotle’s point was not that motion is mysterious. It was that if you refuse to name the first cause, you will pretend the last thing you see is God.[^2]

AI is a last thing we see. The *motore immobile*, if there is one in this picture, is still a person who wanted something, funded it, and left it running.
